A 3D open-world crime game built with Three.js. Play as Kai Reyes, a wheelman climbing the ladder of Solmar Bay's underworld — from your first stolen car to a high-stakes casino heist, guided by fixer Mama Lu. Drive, run, and fight through a sun-soaked procedural city where every wanted star raises the heat.

## Features

- **7 story missions** — car theft, getaways, and a casino heist finale
- **On-foot + driving** — chase camera, car stealing (E), 16 AI traffic cars, 22 pedestrians
- **Wanted system (0–5 stars)** — police cars ram you, a helicopter hunts you at 3+ stars
- **Combat, HUD + canvas minimap**, menus (start / pause / BUSTED / WASTED / story complete)
- **Procedural sun-soaked city**, WebAudio sound effects, and a 3-station procedural radio
- **Save system** — progress stored in localStorage
- **Fully offline** — Three.js is vendored locally, no CDN required

## How to run

Just open `game/index.html` in a browser. If your browser blocks local files, serve the `game/` folder with any static server, for example:

```bash
npx serve game
```

or

```bash
cd game && python3 -m http.server
```

Then open http://localhost:3000 (or the port shown) in your browser.
